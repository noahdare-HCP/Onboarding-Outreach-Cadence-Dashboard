Working days = Mon–Fri only (weekends excluded). The day count uses status-change tracking (it resets each time a case's status/sub-status changes); before any change is observed it falls back to days since the case opened, labelled accordingly. The dashboard always evaluates against today's date.

Outreach cadence rules

Each rule lists the working-day checkpoints when outreach is expected for a Status + Sub-Status combo (e.g. 1, 3, 5 = reach out every other day for three attempts). Matching is case-insensitive and ignores stage suffixes like “#1”. Reps can mark an outreach done from the table: the case then shows Outreach completed until the next checkpoint, when it re-flags as Outreach due. Once every checkpoint is marked done and the case is still open, it flags Urgent · unresponsive through outreach.
